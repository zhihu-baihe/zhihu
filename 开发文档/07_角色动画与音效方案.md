# 《云阙行：九灯照夜》角色 / 动画 / 音效技术方案

> 本文回答三个问题：**角色是怎么来的、动起来靠什么、声音从哪来**。
> 三条都遵守项目硬约束：零预算、无外部资产、改参数即可重现。
> 配套代码：`scripts/actors/humanoid_builder.gd`、`humanoid_rig.gd`、`tools/gen_sfx.py`、`scripts/autoload/audio_director.gd`。

---

## 1. 约束与关键决策

| 需求 | 常规做法 | 本项目做法 | 为什么 |
|---|---|---|---|
| 角色模型 | Blender 建模 + 导出 glb | **代码组装基础网格** | 无建模人力；且换配色/体型不用回 Blender |
| 角色动画 | Skeleton3D + 蒙皮 + 动画文件 | **Node3D 关节层级 + 每帧程序化驱动** | 蒙皮需要权重，属于外部资产；刚体关节可全代码生成 |
| 音效 | 采购 CC0 音效包 | **Python 合成 WAV** | 站点可达性不稳定；中式氛围音（夜风/河水/远钟）难找匹配包；合成可调参 |

三者的共同收益：**整套资产可复现、可参数化、体积小**（音频合计 34.4 秒 / 3MB，角色零文件）。

## 2. 角色建模（`HumanoidBuilder`）

### 2.1 骨架与尺寸

身高按 **1.72 m**；脚底 `y=0`，模型正面朝 **−Z**（与 `PlayerController` 的朝向约定一致）。

```
Rig
└── Hip                      y=0.90   ← 骨盆（走路起伏）
    ├── Skirt / Belt / Weapon（袍摆 · 腰带 · 佩剑）
    ├── Spine                y=+0.06  ← 腰（前倾/扭转/侧倾）
    │   ├── Torso / Lapel / Collar（躯干 · 交领斜襟）
    │   ├── Neck             y=+0.50
    │   │   └── Head / Hair / Band / Bun（头 · 发包 · 束带 · 发髻）
    │   ├── ShoulderL        (+0.208, +0.46)     ← 肩
    │   │   └── ElbowL       (0, −0.27)          ← 肘
    │   │       └── ForeArm / Cuff / Hand
    │   └── ShoulderR        (−0.208, +0.46)
    ├── HipL                 (+0.095, 0)
    │   └── KneeL            (0, −0.42)          ← 膝
    │       └── Shin / Boot
    └── HipR                 (−0.095, 0)
```

| 部位 | 尺寸 |
|---|---|
| 躯干 | 圆柱 ø0.37→ø0.44，高 0.55 |
| 袍摆 | 圆柱 ø0.47→ø0.67，高 0.50（**略外扩直筒，不是喇叭裙**） |
| 头 | 球 r=0.105，压扁 0.94/1.06/0.98 |
| 上臂 / 前臂 | ø0.10 × 0.27 / ø0.09 × 0.26 |
| 大腿 / 小腿 | ø0.16 × 0.42 / ø0.12 × 0.44 |
| 靴 | 盒 0.115 × 0.09 × 0.235 |

### 2.2 配色来源

```gdscript
# NPC：来自 dialogue.json 的 npcs 段
robe  = meta.body     # 主袍色
trim  = meta.color    # 缘边 / 腰带 / 束带 / 领
skin  = meta.skin     # 缺省 #c8a184
hair  = meta.hair     # 缺省 #241f1c
boot  = meta.boot     # 缺省 #2f2a26

# 玩家：player.tscn 上的 @export（沈照野 = 青蓝外袍 + 铜金缘边 + 佩剑）
```

> **配色不写死在逻辑里**：`GameState`/UI 只读数据，角色配色同样从数据取，新增 NPC 只需在 `dialogue.json` 加一行。

### 2.3 材质规则

角色用 `MatCache.cloth()`，带**极弱自发光（0.055）**。这是刻意的：
夜景里角色若完全依赖环境光，剪影会糊进背景（美术标准 §12 要求「角色清晰」）。
发光量只够把轮廓从暗部托出来，不产生「发光人」的观感。

## 3. 动画（`HumanoidRig`）

### 3.1 驱动接口

```gdscript
rig.set_locomotion(speed)   # 外部每帧写入水平速度（m/s），0 = 站立
```

`_process()` 内部完成全部姿态计算，**无需任何动画文件或 AnimationPlayer**。

### 3.2 相位与幅度

```
phase += delta × 1.85 × speed        # 3.4 m/s ≈ 2 步/秒
blend → 1.0（速度 >0.12）或 0.0，按 5.5/s 过渡（避免动作硬切）
```

| 关节 | 公式 | 说明 |
|---|---|---|
| 大腿 | `0.60 × sin(phase)` | 左右反相 |
| 膝 | `−(0.06 + 1.0 × max(0, −sin(phase)))` | **只允许后弯**，蹬地时弯最多 |
| 肩 | `−0.48 × sin(phase)` | 与同侧腿反相 |
| 肘 | `(0.16 + 0.24 × max(0, sin)) × blend + 0.10 × idle` | 静态也略弯，不像木偶 |
| 骨盆高度 | `+ (0.032 × sin(2·phase) − 0.012) × blend` | 每步起伏两次 |
| 骨盆侧摆 | `0.05 × sin(phase)` | — |
| 骨盆转向 | `−0.085 × sin(phase)` | — |
| 躯干 | `前倾 −(0.03 + 0.085×spd)`；侧倾 `0.035 × sin` | 越快越前倾 |
| 袍摆 | `−0.16 × sin(phase)` | 减少腿从摆外穿出 |
| 待机呼吸 | `sin(t × 1.65 + phase_offset)` → 躯干微起伏 + 手臂外张 | `phase_offset` 随机，**各 NPC 不同步** |
| 待机颈部 | `sin(t × 0.62) × 0.055` | 缓慢无意识摆头 |

### 3.3 旋转方向约定（踩过的坑）

模型正面朝 **−Z**，因此：
- `rotation.x > 0` → 部件向 **−Z（前）** 摆。大腿前摆用正角度；躯干前倾用**负**角度。
- 膝/肘的符号相反：膝只能负、肘为正。

## 4. 音效（`tools/gen_sfx.py` + `AudioDirector`）

### 4.1 合成方法

纯 Python 标准库（`math` / `random` / `struct` / `wave`），无 numpy、无下载。
基础工具有：白噪声、一阶低通/高通/带通、正弦、指数包络、归一化、**首尾交叉淡化**（循环无缝）。

| 类别 | 文件 | 合成要点 |
|---|---|---|
| 石板脚步 | `step_stone_1..4` | 噪声脉冲（低通 1.9k + 高通 3.6k）+ 92 Hz 闷响，4 个随机变体 |
| 木板脚步 | `step_wood_1..3` | 更脆 + 205/428 Hz 板腔共鸣 |
| UI | `ui_click` / `ui_hover` / `ui_open` / `ui_close` | 方波瞬态 / 上下扫频 + 钟形包络 |
| 拾取 | `pickup` | 880 / 1320 / 1760 Hz 三连快衰减 |
| 线索 | `clue` | 392→523→659→784 Hz 四音上行，正弦 + 2、3 次泛音（≈古琴） |
| 打字 | `dialogue_blip` | 35 ms 三角波 620 Hz |
| 远钟 | `bell_far` | 110/165/220/330/493/660 Hz **非谐波**部分音 + 敲击瞬态 |
| 灯笼轻响 | `lantern_chime` | 1568 / 2093 / 2637 Hz 三音铃 |
| 环境 | `amb_night` / `amb_water` / `amb_crickets` | 低通噪声 + 阵风 LFO(0.13/0.047 Hz) / 中频流动 / 随机高频脉冲 |

### 4.2 循环与混音

- 生成时对尾部 0.35 s 与头部交叉淡化 → 循环点无缝。
- Godot 导入的 WAV 默认**不循环**；`AudioDirector._load_looped()` 复制一份并写入 `loop_mode / loop_begin / loop_end`。
- 环境音三层增益由地图数据控制：`map_moyi.json` → `ambience: {night: −14, water: −17, crickets: −25}`（dB），
  进入世界时逐帧插值淡入（22 dB/s），离开时淡出。

### 4.3 脚步的触发

```gdscript
AudioDirector.tick_footsteps(speed, delta, grounded)
# 按「移动距离」累计：步行 0.72 m / 疾行 0.95 m 一个步幅
# 音量随速度 ±3 dB；音高随机 0.94—1.07；避免连续两步用同一变体
```
与帧率解耦是关键：按时间触发会在掉帧时出现「连踩」，按距离触发则始终一致。

### 4.4 接入点一览

| 位置 | 触发 | 音效 |
|---|---|---|
| `PlayerController._physics_process` | 每步 | `step_stone_*` |
| `MenuPanel.open()/close()/_set_page()` | 开/关/切页 | `ui_open` / `ui_close` / `ui_click` |
| `Interactor._unhandled_input` | 按 E | `ui_click`（−15 dB） |
| `GameState.add_clue()` | 取得线索 | `clue` |
| `GameState.add_item()` | 获得物品 | `pickup` |
| `GameState.add_party()` | 队友入队 | `ui_open` |
| `DialogueBox._process()` | 每 3 个字 | `dialogue_blip`（−19 dB） |

## 5. 调参指南（改一个数字会发生什么）

| 想要的效果 | 改哪里 |
|---|---|
| 角色变高/矮、胖/瘦 | `HumanoidBuilder` 里各部位尺寸；或在 `dialogue.json` 用 `scale` |
| 换某个 NPC 的袍色 | `dialogue.json` → 该 NPC 的 `body` / `color` |
| 步频变快/慢 | `HumanoidRig.walk_cycle`（默认 1.85） |
| 摆幅变大/小 | `stride_scale`（腿）/ `arm_scale`（臂） |
| 脚步更沉/更脆 | `gen_sfx.py` 里 `step_stone` 的低频 `thud` 幅度 / 低通截止 |
| 环境音更响 | `map_moyi.json` → `ambience` 的 dB 值 |
| 环境音氛围不同 | 换 `amb_night` 的滤波截止与 LFO 频率，重跑脚本 |

**改完音频必须重跑**：`python tools/gen_sfx.py`，然后让 Godot 重新导入。

## 6. 验证方法

| 项 | 命令 / 观察 |
|---|---|
| 数据与流程 | `--headless --path . res://tests/test_data_integrity.tscn` → **42/42**（含 3 项音频资产断言） |
| 冒烟 | `--headless --path . --quit-after 200` → **0 错误 0 警告** |
| 角色外观 | `--shot-view=char`（主角特写）/ `--shot-view=npc`（NPC 特写，站在其正前方拍） |
| 步态 | `--shot-view=walk`（把角色冻结在 `_phase=1.30` 的步态相位上） |
| 音频资产 | 自检里的 `AudioDirector.asset_summary()`：通用音效 9 / 脚步 7 / 环境 3 |

> 步态必须用「冻结相位」的方式截图：静态截图看不出动画，只有这样才可复核前后腿分开、躯干前倾、手臂反相。

## 7. 已知局限与下一批

| 局限 | 影响 | 下一批方向 |
|---|---|---|
| 无手指、无面部表情 | 特写近看是简模 | 需要 Blender 建头部网格 |
| 无衣褶、部件之间为刚体拼接 | 大幅动作会露出接缝 | 同上 |
| NPC 全部站定 | 没有生活气息 | 接 NPC 日程与巡走（`set_locomotion` 接口已预留） |
| 无 BGM、无战斗音 | 章节氛围不足 | 需要器乐采样，合成不适用 → 需要 CC0/授权音乐 |
| 脚步只有石/木两种 | 草地/水面缺失 | 加 `step_grass` / `step_water`（合成脚本里加两个函数即可） |
