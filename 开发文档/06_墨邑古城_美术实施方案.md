> 首个美术任务。按美术指导要求的 A—H 格式输出。

## A. 场景用途与玩家路线

| 项 | 内容 |
|---|---|
| 地图 ID | `MAP_MY_TOWN`（工程：`data/map_moyi.json` → `scenes/world/moyi_town.tscn`） |

| 玩家路线 | 西城门 → 灯市主街 → 百花夜市 → 傩戏台（遇姜阿棠）→ 千灯桥 → 纸扎铺/灯籍小房/河埠（任意顺序）→ 废灯坊侧巷暗门 → 旧灯坊迷宫 |

**美术必须服务的三件事**：① 让玩家在城门内的第一眼就确信「这是座活着的水乡灯城」；② 让三处地标（千灯桥、傩戏台、河埠）一眼可辨、不看任务标记也能找到；③ 让「灯会热闹」与「有人失踪」的反差靠环境读出来，而不是靠对话框。

## B. 主要视觉地标与构图说明

### B1 千灯桥（全图视觉中心，第一优先）

| 项 | 规格 |
|---|---|
| 构图 | 机位在桥北端河对岸，水平视高 9 m、微俯视；桥体居中偏下，暖灯串形成引导线指向主街，桥拱在水面留出完整倒影 |
| 近景 | 河沿石阶 + 木栏杆（前景遮挡 15% 画面） |
| 中景 | 桥体、桥面彩灯串、两侧灯柱 |
| 远景 | 主街灯笼向纵深收束 → 城门楼剪影 → 薄雾中的远山 |
| 光照方向 | 太阳自西偏南 18° 仰角（暖 `#E0A97A`），月色补冷光；水面反射暖灯与冷月两处高光 |
| 玩家可行走区 | 桥面 6.5 m 宽、拱高 2.1 m；桥两端接主街与对岸台地 |

### B2 傩戏台（第二地标，人物登场舞台）

- 构图：从主街来向斜 30° 看戏台正面，红幕占据视觉重心，台前留出可站立空地（姜阿棠登场、纸偶互动）。
- 要素：可辨认的戏幕（红 `#B5543C`）、木骨外露（斗拱 + 柱）、纸绢灯笼、后台入口（阿禾与隐藏戏箱）。
- 要求：能容纳「后台」空间，为后续《最后一折戏》回访演出留结构。

### B3 河埠·第七盏灯（第三地标，情绪停顿点）

- 构图：低机位、独灯近景，画面安静，远离主街热闹；视线沿水面延伸到远处桥影。
- 要求：能读出「这里少了一盏灯」——六盏灯的排布 + 一处空钩。

### B4 其余区域构图要求

| 区域 | 构图要点 |
|---|---|
| 西城门与入城街 | 城门框景：门洞内透出暖灯与街巷纵深，远处主街灯笼成线 |
| 灯市主街 | 一点透视，街道由暖黄渐变到橘红；两侧招牌形成节奏 |
| 百花夜市 | 摊位错落、布棚色彩区分、灯笼高低错落，形成热闹但不乱的密度 |
| 纸扎铺 | 纸扎与半张面具的近景可辨识，铺内暖灯透出 |
| 灯籍小房 | 低矮沿河小屋，案桌与登记册可读，安静偏冷调 |
| 废灯坊侧巷 | 冷灯、封条、斑驳墙面；光线比主街暗一档，暗示「这里不对」 |

## C. 色彩、材质、光照与雾气标准

沿用 `05_美术标准_ArtBible.md` §2—§4，墨邑的具体取值：

| 项 | 墨邑取值 |
|---|---|
| 主色板 | 青黛屋顶 `#46525E` / 石墙 `#A89A88` / 石板 `#7D766B` / 旧木 `#6B4F35` / 河水 `#16333C` / 灯火 `#FFB457` |
| 灯火占比 | 画面 10%—20%；主街可到 25%（灯会），河埠降到 8% |
| **氛围基准** | **蓝调时刻（early_night）**——依据 `ui规范/reference_art/墨邑灯会场景占位图.png` 与 `氛围参考/` 三张参考图复核后确定：冷蓝环境 + 暖灯点缀，冷暖对比即氛围来源 |
| 光照（已实现） | 残照 `#C98A5E` 0.18（仰角 8°）+ 月 `#C8D8FF` 0.55；环境光 0.42；曝光 1.10 |
| 雾（已实现） | `#26314A`，密度 0.011，天空影响 0.40；远景保留 25% 以上可读性 |
| 辉光（已实现） | 强度 0.60，只让灯火溢出 |
| 水面 + 湿石（已实现） | 水面粗糙度 0.08 / 金属度 0.45；街道与广场改**湿石**（粗糙度 0.42）并启用 **SSR**，让灯笼在石面与水面留竖条倒影 |
| 远景第三层（已实现） | 7 座雾中山体剪影 + 2 座层叠塔（河对岸山中塔为视觉落点） |
| 备用档 | `dusk`（暖橙黄昏，H 太阳 0.55）保留在 `environment_presets` 中，序章落灯观开场可用 |
| 待补 | 灯初亮 / 子时 / 事后天明三档接剧情切换；平面反射（仅桥上）；柳条与花枝前景压边 |

**反差点要求**：主街（暖、密、亮）↔ 废灯坊侧巷（冷、疏、暗）↔ 河埠（暖、疏、静）三处必须在**不看台词**的情况下就能感到气氛差异。

## F. 适合用 AI 生成参考图 / 纹理草稿的部分

| 用途 | 可以做什么 | 边界 |
|---|---|---|
| 构图与气氛参考 | 生成 16:9 环境概念图（如本目录 `reference/墨邑_千灯桥_概念参考_v0.1.png`），用于确定机位、色彩倾向、雾与光照方向 | **只作方向参考，不是资产，不进仓库构建路径** |
| 材质草稿 | 生成「青瓦 / 旧木 / 石墙」的质感草稿作为画贴图的参照 | 不能直接当 tileable 纹理入库；必须用 Material Maker / ambientCG 重新生产 |
| 道具设计稿 | 纸扎、面具、戏台幕布的花纹草稿 | 最终仍要 Blender 建模 |
| 环境色板 | 从概念图提取色板校验 §2 的色板是否偏离 | 色板以 `05_…§2.1` 为准，概念图只用于对照 |

**明确禁止**：把 AI 概念图当场景完成证明；把 AI 图直接当纹理或 Skybox 贴进游戏；用 AI 图替代仍缺失的 3D 模型。

## G. 在 Blender 与 Godot 中组合、导入与验证

1. **白模比例验证（先做，不贴图）**：Blender 用 4 m 网格搭 `SM_Building_A`，门洞 1.8×2.1、层高 3.2、台基 0.35；导出 `.glb` 拖进 Godot，与 `yunque/shots/moyi_main_street.png` 并排比对——门高应约等于玩家身高 1.7 m 的 1.24 倍。
2. **模块化拼接**：按 `05_…§5.2` 连接规则拼出「单层铺面 4×10 m」「两层带厦 8×10 m」两种基本型，确认无穿模、无缝隙。
3. **材质**：在 Blender 建立 `M_Wood_Old` / `M_Stone_Wall` / `M_Tile_Roof` / `M_Cloth_Red` 材质模板，参数抄 `05_…§4`；导出后在 Godot 侧按需抽成 `.tres` 共享。
4. **碰撞**：为墙、台基、桥、栏杆建 `<名称>-colonly` 盒体，导出验证 Godot 生成 `StaticBody3D`；不把高模设成三角网碰撞。
5. **替换灰盒**：改 `town_builder.gd` 的 `_building` / `_bridge` / `_lantern_row` / `_stall` / `_stage` / `_prop`，把 `_box()/_prism()/_cylinder()` 调用换成 `SM_*/PROP_*` 实例化；**`data/map_moyi.json` 的坐标与交互点一律不动**。
6. **光照升级**：正式资产到位后把灯笼动态光从 30 盏降为「关键 6—8 盏 + LightmapGI 烘焙」，其余靠自发光材质。
7. **回归验证（每批必跑）**：
   ```
   godot --headless --path E:/MyGame/yunque --quit-after 200          # 冒烟：0 错误
   godot --headless --path E:/MyGame/yunque res://tests/test_data_integrity.tscn   # 24/24
   godot --path E:/MyGame/yunque --resolution 1600x900 -- --screenshot=… --shot-view=town|bridge|player
   ```
   人工确认：路线连续、无卡点、交互距离 3.4 m 内可触发、门/桥尺寸与角色比例正确。
8. **性能记录**：调试器 → 监视器，记录三角面 / draw call / 帧时间，写入 `03_开发日志.md`。
