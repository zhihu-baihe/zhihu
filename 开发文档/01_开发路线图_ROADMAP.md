# 开发路线图 ROADMAP

> 原则（来自用户 brief）：一次只完成一个明确目标；优先在现有架构上最小改动；先跑通最小可玩版本，再加美术与复杂机制。
> 垂直切片顺序（来自设计文档）：**墨邑花灯节 → 青蚨渡 → 蜀岚剑宗 → 批量扩展**。本工程先做墨邑。

## 里程碑与验收标准

### ✅ M1 工程骨架 + 墨邑城镇灰盒（已完成）

**目标**：把墨邑古城跑起来——能走、能看、能与人说话、能查出线索、能接完一条支线。

**验收（已实测）**
- 无头冒烟运行 200 帧：0 个脚本错误。
- 数据与流程自检：24 项断言全通过。
- 实机截图 3 张（全城俯瞰 / 千灯桥 / 出生点街景），画面可读出「黄昏灯会古城」。
- 三条线索任意顺序可查；暗门在线索齐全时可开（不软锁）。
- 同一 NPC 在「初入城 / 得到线索后 / 支线完成后」有不同对白。

### M2 旧灯坊迷宫 + 存档

- 迷宫五个主题空间（MY-D01 封灯门 / MY-D02 纸轿廊 / MY-D03 借面戏台 / MY-H01 隐藏戏箱 / MY-D04 倒悬灯街）。
- 存档系统：旗标、线索、任务阶段、物品、队伍、一次性对白标记、地图时段、`SaveVersion`。
- 验收：存档→退出→读档后，NPC 阶段、线索计数、暗门状态一致；不重播已看过的一次性过场。
- 依赖：M1 的 `GameState` 已按可序列化结构设计（`flags/clues/items/party/seen_dialogues/time_band`），存档只需序列化这几项。

### M3 战斗系统（行动条半即时指令制）

- 行动槽 0—1000，每秒 `SPD × 1.0`；默认等待模式（选指令暂停），可选流动模式 25%。
- 指令：攻击 / 技能 / 道具 / 防御 / 观察 / 逃跑；战意 0—100 与终结技。
- 命中 `clamp(技能命中 + ACC - EVA, 65%, 98%)`；POISE 破韧；状态以「目标行动次数」计时。
- 数值与技能全部读 `data/`（对应 DT_Skills / DT_Enemies / DT_StatusEffects），不写进脚本。
- 验收：教学战（风鬃鼠 ×2）1—2 分钟内结束；全程普攻也能赢；MP 不足时按钮禁用且不消耗行动。

### M4 百面灯魇四阶段 BOSS

- 迎灯 / 借面 / 倒悬灯街 / 空面；阶段阈值只在一次行动结算后判定（避免连续过场）。
- 线索齐全（`ALL_CLUES`）时第二阶段提前给出本体提示（`BOSS_BAOMIAN_EXTRA_HINT`）。
- 战败回到首领前检查点，不重置线索与支线状态。

### M5 装备 / 锻造 / 材料经济

- 槽位：主武器 / 衣装 / 护符 / 饰品×2；固定配方、不做强化失败与随机词条。
- 功能差异优先于数值差异（如「每场战斗首次受推拉位移 -30%」）。

### M6 序章《借灯下山》

- 落灯观 → 山道教学战 → 砺剑镇 → 吞风巷 → 吞风蜃犬三阶段。
- 复用 M1 的城镇生成器与任务/对白数据层；砺剑镇只是另一份 `map_*.json`。

### M7 美术 pass（灰盒 → 正式资产）

- 用 `TownBuilder` 的 `_building/_stall/_lantern_row` 等函数替换为模块化模型实例，布局 JSON 不动。
- 材质/光照/雾/环境音/镜头视线打磨。

### M8 完整闭环与回归

- 序章 → 第一章连续可玩；存档跨章节兼容；全套回归测试脚本化。

## 风险清单

### P0（会一票否决，必须先处理）

1. **存档缺失**：现在所有进度都在内存里，关掉游戏即归零。M2 必须先做存档，否则后续所有内容都无法验证「读档后状态一致」。
2. **战斗与探索的状态边界**：进入战斗/迷宫必须能干净地切出、切回，且不丢失城镇状态。这要求 M2 就把「地图状态 = 数据」写死，不允许把状态挂在节点上。
3. **灰盒资产溃烂**：如果一直用胶囊体 NPC + 盒子建筑，视觉会长期停在原型。M7 的关键是把生成器函数替换为模型实例，而不是重写布局。

### P1（会疼，但不致命）

1. **对话量爆炸**：设计文档要求核心 NPC 至少 4 个阶段对白。当前 M1 只覆盖 5 名核心 NPC 的部分阶段，剩余靠默认闲聊兜底。需要在 M2 用数据补，而不是加代码分支。
2. **光照预算**：当前 30 盏动态灯是灰盒上限。正式美术若每盏灯都带光源，需要改用烘焙/自发光贴图或分层加载。
3. **中文路径与工具链**：Godot 工程放在纯 ASCII 路径 `E:/MyGame/yunque`，文档目录用中文。后续脚本/构建命令不要把工程路径改成中文。
4. **单一时段**：`time_band` 字段已预留，但只实现了黄昏一个时段。设计文档要求黄昏/灯初亮/子时/事后天明四段，需要 M2 与剧情节点联动。
