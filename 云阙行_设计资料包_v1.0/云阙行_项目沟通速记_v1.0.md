# 《云阙行：九灯照夜》项目沟通速记 v1.0

> 本文件用于新对话快速恢复项目背景。详细规则、原型图、数值表请以《云阙行_九灯照夜_游戏设计总档_v1.0.docx/.pdf》为准。

## 项目定位

- 原创东方仙侠单机 RPG；目标等级 1—80；主线估算 40—50 小时，全支线目标 70—90 小时（均为规划目标，需试玩校准）。
- 目标画面：现代高质量 3D 仙侠场景；暖灯与冷月、真实材质层次、角色轮廓可读、技能特效克制；不把 AI 概念图当作实机资产。
- 目标引擎：Unreal Engine 5.8（正式开始时复核 Epic Launcher 当前可用版本）；先用墨邑花灯节做垂直切片，再分段扩展。
- 战斗：行动条半即时指令制。默认等待模式，指令选择时暂停行动槽；可选流动模式让行动槽以 25% 速度继续。保留经典指令 RPG 的策略节奏，但技能、UI、数值和具体实现原创。
- 御剑：在蜀岚剑宗中期解锁，用于地图切换、高处探索、隐藏区域和少量空中战斗；不是整部游戏的世界观主轴。

## 核心世界观

- 死者沿归水前往九灯城，经核验与登记后由归灯台引渡。
- 无名客：因姓名、籍贯、死亡记录等缺失而无法入册的亡魂；不天然邪恶。
- 86 年前沉灯城遭特大洪灾。司水监引洪保住上游州府，沉灯城居民未能充分撤离。灾后掌灯判官陆太微删改名册，沉灯城被登记为灾前无人居住。
- 城隍晏平川为阻止百姓被遗忘，取走第九盏归灯，将亡魂留在最后一天，反而让他们无法正常离开。
- 主题：名字、记忆、亡者的归处与活人的责任。支线不能全部收束到沉灯城。

## 四名主角

- 沈照野：剑修，寻找姐姐沈青梧；从“重要事情以后再说”成长为愿意给别人指路的人。
- 姜阿棠：傩戏/符修，寻找父亲留下的《沉灯记》；嘴毒、爱钱、心软，最终补完最后一折戏。
- 闻潮：云海舟师/枪修，追查白鲸舶失踪；从幸存者自责走向继续航行。
- 裴渡：九灯城夜行吏/判吏，寻找自己的生死册；从服从规条成长为愿意走进档案之外的人。

## 战斗与技能

- 行动槽 0—1000；拟定每秒增加 SPD 数值，阈值与动画节奏需以试玩校准。
- 核心属性：HP、MP、ATK、MATK、DEF、RES、SPD、ACC、EVA、POISE、战意。
- 战意：普通攻击、防御、打断、弱点攻击积累；100 点释放终结技。
- 五灵：风（速度/位移）、水（治疗/减速/湿润）、火（爆发/灼烧/破甲）、木（缠绕/持续/召灵）、山（护盾/格挡/反击）。
- 组合：水→火浇熄灼烧；风+火扩散火势；水+木缠生；山+火熔甲；水+风回潮；木+山根壁。
- 技能、仙术和状态的数值原型都在总档第 5—6 章；均是首轮测试值，不能视作最终平衡。

## 工程实现路线

1. 先制作墨邑花灯节垂直切片：可探索城镇、NPC 对话、3 条主线线索、1 条支线、普通战斗、百面灯魇四阶段 BOSS、任务日志和存档。
2. 再做青蚨渡，验证水域机制、第二队友、跨地图任务与保存状态。
3. 再做蜀岚剑宗，验证门派日常、技能成长、御剑与地图切换。
4. 三段稳定后，开始批量制作后续区域。
5. UE 项目内容优先采用数据驱动：技能、怪物、状态、任务和 BOSS 阶段分离配置；避免将内容硬写在单一关卡蓝图。
