# 剧情档案使用说明

本包是《云阙行：九灯照夜》的剧情与文本专用档案，独立于武器/属性系统文档。Word/PDF 总档用于通读与评审；各章、各任务的 Markdown 文件是推荐的长期修订源。目录根部的《云阙行_剧情与对白全集_源文本_v1.0.md》是全文检索合并版，便于交给 AI 阅读，但不要把它当作唯一编辑源。

## 目录
- `00_项目入口/`：项目圣经、目录索引、修订规则、设定锁定表。
- `01_世界观与历史/`：九州、九灯司、归水、沉灯城事件、时间线。
- `02_人物档案/`：主角团、家庭/师门、关键对手人物弧。
- `03_主线剧本/`：按五卷与章节拆分的主线剧本。每章包含目标、场景、关键对白、敌人与 Boss、伏笔、支线钩子。
- `04_支线任务/`：按地图与人物长线拆分的支线任务卡，含触发条件、步骤、对白、结局、奖励。
- `05_对白与演出/`：对白口吻、演出规则、关键场景台词。
- `06_伏笔与回收/`：线索账本、首次出现与回收章节、避免过早揭示的规则。
- `07_地名与术语/`：术语表、角色/地名命名规范。
- `08_修订记录/`：版本变更记录与待决问题。

## 修订原则
1. **先改源 Markdown，再更新汇编 Word/PDF。** 每章 `.md`、每个任务卡 `.md` 是可追踪的主文本；全文检索版和汇编文档用于查阅，不作为唯一编辑源。
2. 新增人物或地点前先查 `07_地名与术语/命名与术语表.md`，避免重名、同音冲突与设定漂移。
3. 任何改动沉灯城、晏平川、陆太微或第九盏归灯的设定，都要同步改 `06_伏笔与回收/伏笔账本.md`。
4. 支线不要求全部服务主线。至少三分之一支线应当只是当地人的生活、愿望或麻烦。
5. 对白先写人物目的，再写字句；禁止让所有角色用同一种“深刻金句”说话。
6. 目前文本属于可改的剧情基线，不是已锁定的最终游戏对白。对白可继续扩写成逐句演出脚本。

## 设定状态
- 【锁定】四名常驻队员：沈照野、姜阿棠、闻潮、裴渡。
- 【锁定】九灯城与沉灯城为核心；御剑于中期蜀岚剑宗解锁，主要用于地图旅行和特殊探索。
- 【锁定】战斗为行动条半即时指令制。
- 【锁定】前期轻快，中期奇闻壮阔，后期沉静悲情。
- 【锁定】主线不复活全部亡者；记名不等于复生。
- 【拟定】等级 1—80；章节顺序与区域名为 v1.0 基线，可在不破坏因果链的前提下调整。
