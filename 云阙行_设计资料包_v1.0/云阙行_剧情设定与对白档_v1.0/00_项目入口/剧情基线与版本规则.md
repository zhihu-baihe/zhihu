# 剧情基线与版本规则

## 版本 v1.0
这是第一份统一剧情档案，负责把此前讨论过的核心故事、人物、地图和支线整理为可维护结构。此版本不宣称所有 NPC 的所有可选台词已经写完；关键主线场景已有对白初稿，章节文件明确了需要继续扩写的部分。

## 已锁定
- 主线主轴：失踪街道 → 九灯司 → 无名客 → 沉灯城名册 → 晏平川与陆太微 → 归灯渊。
- 角色：沈照野、姜阿棠、闻潮、裴渡；沈青梧、闻不归、谢停云、楚三千、晏平川、陆太微为重要配角。
- 中期御剑于蜀岚剑宗解锁，主要影响地图旅行、探索与少量战斗。
- 主线等级 1—80，19 个章节，5 卷。
- 最终并非所有死者复活；记名让人不被制度抹除，但无法逆转死亡。

## 修改需同步
- 主线改动：更新章节文件、章节索引、伏笔账本与总档。
- 人物动机改动：更新人物档案和每章对白。
- 支线改动：更新对应任务卡、任务索引与奖励表。
- 地名改动：更新术语表、世界地图、章节标题及相关地图数据。
