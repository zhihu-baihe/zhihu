# 待决问题（不阻止继续写章）
1. 沈青梧在沉灯城帮助亡魂的具体年份与所用身份需要在完整章节对白前锁定。
2. 闻不归是否知晓沈青梧仍活着，建议前期只知道她去追查旧地名，中期才知道她主动留在城中。
3. 沉灯城洪灾当年的水利方案需要保留复杂性：改道确实避免上游更大灾难，但撤离与删册是不同层面的责任。
4. 晏平川最后交出归灯之后，不应立即无条件得到宽恕；通过居民自主选择、引渡与之后的记录完成弧线。
5. 终局的无名相是众多未归籍亡魂的混杂状态，不是单独一位隐藏魔王。
6. 支线奖励最终需与战斗、武器、角色属性文档对齐，防止道具重复或数值冲突。
7. 各章节的具体日期、季节与旅行时间需在地图制作阶段进一步做时间线表。

# 每次修订必查
- 角色的愿望、恐惧、成长是否仍一致；
- 线索首次出现与回收章节是否匹配；
- 支线任务状态与主线对话是否冲突；
- 地名、NPC、物件名称是否重名；
- 任何改动是否令后续 BOSS 动机失效。
