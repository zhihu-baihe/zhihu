# CH-07 太华洞天：炉中旧约

**章节编号：** CH-07  
**建议等级：** 27—30  
**主要地图：** 太华洞天、药圃、炼丹室、丹炉秘洞

## 本章目的
讨论长生欲望与修仙的代价；不把所有修仙者写成反派。

## 情节推进
1. 队伍为修复旧地图寻找灵墨，进入太华洞天。
2. 长老弟子因一批“延寿丹”发生争执，有人短暂恢复精力却开始丢失记忆。
3. 调查失败丹方与药圃记录，发现寿命转移的实验。
4. 守炉真人拒绝交出丹方，战斗在三座轮转丹炉间展开。
5. 主角团选择销毁错误丹方，救治受影响弟子；不取走所有研究成果。

## 敌人与战斗
药童傀、灵芝精、丹炉鬼、石阶守灵；精英：失心丹师。

### 区域 BOSS
守炉真人：药鼎与火符；三炉轮转；火金法身。

## 关键对白（剧情稿 v1.0）
### 丹房外

沈照野：修仙到底为了什么？
姜阿棠：先问能不能不交住宿费。
闻潮：为了有本事活下来。
裴渡：依照洞天典籍，修行目标因人而异。
姜阿棠：你看，四个人四个答案。别急着找一个最漂亮的。

### 长老战后

守炉真人：我只想让师父多活几年。
闻潮：那你有没有问过他，愿不愿意拿别人的命换？
守炉真人不答。
姜阿棠：你要是真的想救他，就别让他醒来之后还得替你认错。


## 本章揭示与伏笔
“求长生”不是单纯的恶；一个人最初出于爱，也可能逐渐越过底线。

## 支线入口
- 炉中旧约：整理失败丹方。
- 药圃借苗：帮助年轻药师找回罕见灵草。
