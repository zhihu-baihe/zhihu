# CH-05 鱼凫故城：青铜树下

**章节编号：** CH-05  
**建议等级：** 18—22  
**主要地图：** 鱼凫故城、青铜神树、祭坛地下层

## 本章目的
引入古蜀风格的神树与面具意象，给主线一份可信的历史证据，不要把神秘文明简化成单一答案。

## 情节推进
1. 主角团为修复风路图进入故城，城中铜铃在夜间自行鸣响。
2. 机关守卫将他们视作破坏祭仪者，遗迹中出现可播放片段式回忆的铜镜。
3. 玩家修复神树根部机关，发现古代引魂图。
4. 金面祭主将古城误判为受侵者，战斗需依靠环境机关。
5. 祭文显示九灯司早期职责是登记和引渡，后世才将身份记录与地方籍贯绑定得过于严苛。

## 敌人与战斗
青铜侍卫、面具火鸦、神树藤、铜皮灵兽；精英：纵目祭官。

### 区域 BOSS
金面祭主：长戈盾击；神树空中平台；三只神鸟；根部机关破坏。

## 本章揭示与伏笔
“无名客”在古代文书中称“未归籍者”；历史制度原本更宽容，后来因灾害与官僚处理方式变化。

## 支线入口
- 铜铃不响：修复一组神树铜铃。
- 无眼面具：寻找三块面具碎片并还给遗迹守人。
