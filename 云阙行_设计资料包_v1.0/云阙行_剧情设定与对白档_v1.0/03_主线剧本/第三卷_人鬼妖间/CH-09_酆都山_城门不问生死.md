# CH-09 酆都山：城门不问生死

**章节编号：** CH-09  
**建议等级：** 34—39  
**主要地图：** 酆都山、酆都城、鬼市、判司、归水桥

## 本章目的
让九灯制度首次完整出场。酆都是人鬼交界的仪式城与转运口，不等同于九灯城；它不是单纯恐怖迷宫，而是一座有职业、规矩和生活的地方。

## 情节推进
1. 主角团通过归水桥入城，先被当作手续不全的活人扣下。
2. 裴渡作为夜行吏登场，发现最近无名客数量激增。
3. 玩家在鬼市与判司间查找一份旧生死册。
4. 阎罗案首把部分亡者的名字写入禁令，战斗既需输出也需保护亡魂。
5. 取得裴渡残缺身份档案，决定跟队伍查清自己来历。

## 敌人与战斗
纸衣鬼、归水尸、铜面夜巡、灯芯虫、无面客；精英：铜面夜巡使。

### 区域 BOSS
阎罗案首：判词封技；生死簿场景变形；亡魂保护阶段。

## 本章揭示与伏笔
亡魂登记制度出现漏洞，普通鬼差大多尽力维持秩序，不知高层删册。裴渡确定自己是失籍者。

## 支线入口
- 鬼市借一夜春天：替无名客种桃树。
- 不肯投胎的狗：帮老狗找到主人后代。
- 借来的名字：有人曾主动交出身份牌。

## 场景制作提醒
- 本章至少包含一个纯生活场景，不要所有 NPC 只为交任务而存在。
- BOSS 开战前后都要有角色反应，避免只弹出任务奖励。
- 对白写到正式脚本阶段时，应补充动作、表情、镜头、可跳过规则和触发条件。
