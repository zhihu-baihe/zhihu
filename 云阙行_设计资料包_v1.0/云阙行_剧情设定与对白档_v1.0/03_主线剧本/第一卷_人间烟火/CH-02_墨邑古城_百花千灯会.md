# CH-02 墨邑古城：百花千灯会

**章节编号：** CH-02  
**建议等级：** 5—10  
**主要地图：** 墨邑古城、灯市、河桥、旧戏台、北街祠

## 本章目的

让玩家喜欢姜阿棠；展示节日、地方风俗与第一场有多阶段机制的妖物战；《沉灯记》首次登场。

## 情节推进

1. 主角团进入墨邑，上元前后城中热闹，玩家可参与猜灯谜、做灯、听戏、替摊主找货。
2. 姜阿棠在戏台上表演傩戏，发现一张不该出现的旧面具。
3. 夜间灯会的灯笼逆流而上，迎亲队伍出现，女孩失踪。
4. 追查发现傩神被亡者执念侵蚀，真正的女孩早已死亡但其姓名未被记录。
5. 战后，姜阿棠取得父亲剧本《沉灯记》残页，决定同行。

## 敌人与战斗

纸鹤精、花灯蛾、红绳尸、爆竹灵、迎亲纸人；精英：绣灯伥。

### 区域 BOSS

百面灯君：十二灯召纸人；倒悬灯阵改变站位；空白面具复制玩家上一轮技能。关键解法是以唱词辨名并熄灭灯阵节点。

## 关键对白（剧情稿 v1.0）

### 灯市

姜阿棠：看傩戏么？不贵，三文一位。  
沈照野：昨天你还说五文。  
姜阿棠：昨天是好位置，今天你站得偏。  
沈照野：我站得偏还更便宜？  
姜阿棠：看戏要看心情。你这张脸不适合坐前排。

### 迎灯队伍出现

闻灯人：门关好。三更以后听见锣声，不要答应。  
沈照野：为什么？  
闻灯人：因为它问的不是你愿不愿意嫁，是你还记不记得自己死了。

### 战后

女孩：哥哥，你知道回家的路吗？  
沈照野：我……可以送你去找人。  
姜阿棠轻轻摇头：有的路，得她自己走。  
女孩：那你们记得我吗？  
姜阿棠：记得。你叫小绢。你今天穿了蓝裙子，袖口有一朵小花。  
女孩笑了：好。这样就够了。

## 本章揭示与伏笔

傩神原本负责迎送亡魂，被未被登记的亡者执念侵蚀。姜阿棠的父亲曾搜集同类故事。

## 支线入口

- 百花灯匠：帮匠人找回被小妖偷走的灯芯。
- 戏台后门：寻找失传唱腔，解锁姜阿棠技能演出。
- 灯下第七盏：第一阶段，只交代老妇人的七个孩子。

## 场景制作提醒

- 本章至少包含一个纯生活场景，不要所有 NPC 只为交任务而存在。
- BOSS 开战前后都要有角色反应，避免只弹出任务奖励。
- 对白写到正式脚本阶段时，应补充动作、表情、镜头、可跳过规则和触发条件。
