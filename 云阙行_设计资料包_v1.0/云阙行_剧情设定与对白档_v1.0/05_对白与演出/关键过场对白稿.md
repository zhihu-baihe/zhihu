# 关键过场对白稿

本文件收纳需优先打磨的核心场景。完整分章对白见 `03_主线剧本/` 内各章文件。

## SCN-01 落灯观交灯
闻不归：下山一趟。把这盏灯送给桃灯镇的谢老头。  
沈照野：谢老头不是前年就没了吗？  
闻不归：所以才该问问，他欠的酒钱准备什么时候还。  
沈照野：师父，你总有一天会被自己的账本害死。  
闻不归：那你记得把我葬远一点，省得酒馆老板来讨账。

## SCN-02 姜阿棠第一次同行
姜阿棠：我跟你走一段。  
沈照野：为了找那条街？  
姜阿棠：为了你撞坏的摊子。那条街要是真没了，我找谁索赔？  
沈照野：你这人怎么一点都不讲道理。  
姜阿棠：讲道理又不能赔钱。

## SCN-03 闻潮加入
闻潮：我跟你们走，不是因为信你们。  
沈照野：那因为啥？  
闻潮：你们手里的图，画着白鲸舶最后停靠的水域。  
姜阿棠：那要是找到后什么都没有呢？  
闻潮：那就什么都没有。总得看一眼。  
她把罗盘收进怀里：别误会，我只负责带路，不负责哄人。

## SCN-04 裴渡决定离开九灯城
裴渡：按规矩，我不应离开辖区。  
沈照野：那你留下。  
裴渡：但按现有档案，我本人也是一名未归籍者。  
姜阿棠：所以？  
裴渡：我需要亲自查明。  
闻潮：这才像句人话。走吧。

## SCN-05 晏平川最后对话
晏平川：他们在这里有饭吃，有门可回，有人叫他们的名字。你们把灯点亮，他们就得走。  
沈照野：我不想让他们再被忘记。  
晏平川：那你就该让他们留下。  
沈照野：留下来，和被关在这里，不是一回事。  
晏平川：若他们走了，谁来记得？  
姜阿棠：我们。之后也会有人记得。不是一次记住，就能管一辈子。  
晏平川：你们凭什么保证？  
裴渡：不能保证。只能把名字先写下来，再让活着的人接着做。
