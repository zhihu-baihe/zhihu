# 人物档案：晏平川

**编号：** CHAR-09  
**身份/定位：** 沉灯城城隍；悲剧性对手  
**年龄：** 亡故86年

## 外在表现
曾是谨慎、负责的城隍；灾后逐渐固执，不再相信制度能保护百姓。

## 表层愿望
让沉灯城三万六千二百一十一名居民不被世界遗忘。

## 深层恐惧
放手之后，这些人会第二次死去——第一次死于洪水，第二次死于无人在意。

## 人物弧线
从保留真相的守护者变成把所有人困在最后一天的人；最后必须承认“记住他们”不等于“替他们决定永远留下”。

## 对白口吻
庄重但不神秘；谈到普通居民时说的都是饭、家门、孩子、街巷。

## 重要物件
第九盏归灯、城隍长剑、沉灯城旧名册。
