# 人物档案：谢停云

**编号：** CHAR-07  
**身份/定位：** 蜀岚剑宗弟子；竞争者与后期盟友  
**年龄：** 20左右

## 外在表现
天赋高、好胜、重视规矩与名次，最初觉得沈照野散漫且不配拿到御风令。

## 表层愿望
成为能让师门骄傲的剑修。

## 深层恐惧
若不够优秀，自己就没有价值。

## 人物弧线
通过“十七场败仗”支线学习输赢之外的责任；最终不是被主角收服，而是成为能够独立做决定的人。

## 对白口吻
初期锋利、正式；后期更少挖苦，学会直接承认失误。

## 重要物件
不鸣剑的旧剑鞘、问剑榜、同门令。

## 写作禁区
- 不用长段抽象道理替代人物行动。
- 不把角色缺点在一章内轻易治好。
- 关键关系变化必须通过共同经历、选择或物件体现。
