# 人物档案：闻不归

**编号：** CHAR-05  
**身份/定位：** 落灯观师父  
**年龄：** 年长

## 外在表现
脾气古怪、爱喝酒、练剑时严厉、生活上粗心；常把同一件往事讲两三遍。

## 表层愿望
让沈照野有能力独自走完自己的路，而非永远活在师长的安排里。

## 深层恐惧
自己传下去的不是剑法，而是一种把责任推给下一代的习惯。

## 人物弧线
不走传统“师父最后牺牲”的简单路线；他在前期负责生活气和规则，中后期逐渐透露自己知道沉灯旧案的部分边角，最终在尾声接受后辈以自己的方式解决问题。

## 对白口吻
话少、干脆、偶尔用一句生活经验打断大话。

## 重要物件
旧灯、酒葫芦、落灯观门规、旧剑修理记录。

## 写作禁区
- 不用长段抽象道理替代人物行动。
- 不把角色缺点在一章内轻易治好。
- 关键关系变化必须通过共同经历、选择或物件体现。
