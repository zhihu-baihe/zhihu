# SQ-026 一碗没凉的面

**任务编号：** SQ-026  
**区域：** 九灯城  
**类型：** 城内生活  
**触发条件：** 客栈老板每日都会给空桌放一碗面。

## 流程
询问不同鬼客；找出桌上留下的半枚铜钱；发现面是为一名长期未归的夜巡吏准备。

## 关键对白
老板：客人说会回来，我就给他留一碗。
姜阿棠：八十六年都没来？
老板：那就更不能凉了。

## 结局与后续
知道真相后，老板仍留桌，但只在节日摆一次。

## 奖励
店家折扣；裴渡对话。
