# SQ-016 借来的名字

**任务编号：** SQ-016  
**区域：** 晦明鬼市／九灯城  
**类型：** 跨章节身份支线  
**触发条件：** 鬼市账簿中发现一个商人名字重复登记。

## 流程
分别核验两份身份牌；找到一封交易信；得知商人自愿把身份牌交给另一名亡魂，帮助对方回人间见家人。

## 关键对白
商人：名字是我给他的，不是他偷我的。
裴渡：但手续上不允许。
商人：那你是相信我，还是相信一张木牌？

## 结局与后续
裴渡学会把人的陈述和物证一起记录，而非只认其中一种。

## 奖励
录名笔注灵配方。
