# SQ-018 第十三人

**任务编号：** SQ-018  
**区域：** 鸣沙壁城  
**类型：** 文书谜题  
**触发条件：** 壁画里出现第十三个旅人。

## 流程
对比三幅不同年代壁画；用旧历文书推测其出现时间；找到守窟人记载，确认旅人是后来来此的记录员。

## 关键对白
守窟人：有时画里多一个人，不是因为画师画错了。
姜阿棠：是因为后来有人来了。
守窟人：对。事情并不总是谜。

## 结局与后续
开启隐藏石窟与风路捷径。

## 奖励
古历图谱、探索经验。
