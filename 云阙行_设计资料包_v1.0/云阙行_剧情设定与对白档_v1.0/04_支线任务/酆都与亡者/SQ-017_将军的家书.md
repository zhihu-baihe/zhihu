# SQ-017 将军的家书

**任务编号：** SQ-017  
**区域：** 赤崖古战场  
**类型：** BOSS 和平收尾  
**触发条件：** 战场营地发现一封未寄家书。

## 流程
收集三封家书与一枚旧军令；在BOSS战前与将军对话；战斗中出现一次可选的“出示家书”。

## 关键对白
将军：孩子会骑马了？
沈照野：会。
将军：那我该回去了。
裴渡：将军，路已经不在了。
将军：我知道。送我到营门就好。

## 结局与后续
将军带着残兵离开循环战场。

## 奖励
碎碑武器图谱、战魂军阵技能说明。
