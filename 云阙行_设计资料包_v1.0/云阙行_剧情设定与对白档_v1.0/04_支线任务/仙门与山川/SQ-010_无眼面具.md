# SQ-010 无眼面具

**任务编号：** SQ-010  
**区域：** 鱼凫故城  
**类型：** 收集／叙事  
**触发条件：** 祭坛旁的无眼面具无法归位。

## 流程
收集三块碎片；询问守窟人面具曾用于祭仪还是戏剧；最终让玩家决定将面具放回祭台或交给博物师保管。

## 关键对白
守窟人：谁说没有眼睛，就看不见？
裴渡：从登记角度，它至少无法确认所属者。
姜阿棠：人家问的是看不看得见，不是填什么表。

## 结局与后续
两种选择都不影响主线，仅改变后续 NPC 台词。

## 奖励
外观面具；小幅抗幻。
