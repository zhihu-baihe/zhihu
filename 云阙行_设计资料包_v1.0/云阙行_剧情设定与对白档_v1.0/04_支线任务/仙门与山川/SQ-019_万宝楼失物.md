# SQ-019 万宝楼失物

**任务编号：** SQ-019  
**区域：** 蓬莱仙市  
**类型：** 轻松／装备  
**触发条件：** 三名顾客分别声称买错法器。

## 流程
检查收据与物品；帮他们把符灯、护腕和自动梳发剑交还正确主人；可以选择收取少量手续费或免费协助。

## 关键对白
摊主：做生意最难的是客人说不清自己买了什么。
姜阿棠：不，最难的是客人说清了还想退。

## 结局与后续
店铺开放特殊材料交换。

## 奖励
