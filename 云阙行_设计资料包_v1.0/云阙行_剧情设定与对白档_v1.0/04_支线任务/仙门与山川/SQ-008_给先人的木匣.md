# SQ-008 给先人的木匣

**任务编号：** SQ-008  
**区域：** 百棺峡  
**类型：** 探索／文化  
**触发条件：** 一户村民的木匣被盗。

## 流程
检查岩壁、盗墓营地与祭祖场；找到木匣后可选择由家属亲自放回或交给寨老。

## 关键对白
村民：里头没值钱东西。
沈照野：那他们为什么偷？
村民：他们总觉得，别人家的念想拿走也不算偷。

## 结局与后续
村民把木匣内容读给孩子听，后代决定继续保留这项习俗。

## 奖励
护身木牌；山地陷阱识别。
