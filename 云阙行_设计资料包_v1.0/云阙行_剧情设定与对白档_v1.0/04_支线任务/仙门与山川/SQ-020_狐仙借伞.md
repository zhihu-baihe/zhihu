# SQ-020 狐仙借伞

**任务编号：** SQ-020  
**区域：** 青丘夜宴  
**类型：** 报恩／地方奇谈  
**触发条件：** 山下商人称油纸伞被狐妖拿走。

## 流程
跟踪伞上的狐毛；发现狐妖每逢雨天把伞留在山口为旅人挡雨；找商人后人确认祖辈救狐的往事。

## 关键对白
商人后人：一把旧伞，不值钱。
姜阿棠：那为什么找？
商人后人：我祖母说，丢了人家的东西，得想办法还。

## 结局与后续
狐妖继续守路，但不再偷偷拿伞。

## 奖励
避雨披风外观、风系材料。
