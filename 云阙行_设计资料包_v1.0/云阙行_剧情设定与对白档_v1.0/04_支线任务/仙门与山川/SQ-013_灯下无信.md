# SQ-013 灯下无信

**任务编号：** SQ-013  
**区域：** 照海城  
**类型：** 人物／情感  
**触发条件：** 老船工每年放一艘无名灯船。

## 流程
找到妻子当年留下的航海手札；手札中只有家常计划，没有遗言；返回灯节前交给船工。

## 关键对白
手札：回来以后，记得把窗框修一修。下雨时总漏。
老船工读完：她总说这个。

## 结局与后续
老船工第一次在灯节结束前回家。

## 奖励
海潮挂饰、闻潮好感事件。
