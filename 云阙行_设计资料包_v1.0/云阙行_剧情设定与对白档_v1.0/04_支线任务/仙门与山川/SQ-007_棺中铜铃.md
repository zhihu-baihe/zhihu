# SQ-007 棺中铜铃

**任务编号：** SQ-007  
**区域：** 百棺峡  
**类型：** BOSS 和平条件  
**触发条件：** 山寨老族长请求找回三枚悬棺铜铃。

## 流程
找回被盗墓者拿走的两枚，第三枚在失控的棺阵中；不破坏主棺即可取出。

## 关键对白
老族长：棺不是锁，铃也不是钥匙。是让后来的人知道，里面有人。

## 结局与后续
百棺公 BOSS 战前可通过铜铃安抚一部分亡魂。

## 奖励
百棺公战斗难度降低；独特挂饰。
