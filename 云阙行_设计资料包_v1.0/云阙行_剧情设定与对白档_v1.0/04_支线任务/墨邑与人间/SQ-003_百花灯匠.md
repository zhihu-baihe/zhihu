# SQ-003 百花灯匠

**任务编号：** SQ-003  
**区域：** 墨邑古城  
**类型：** 制作／节日  
**触发条件：** 灯匠的十二盏花灯缺失三种灯芯。

## 流程
在花市、河埠和戏台找材料；用不同颜色的纸决定灯会后街道的灯饰样式；交付后可在后续章节看见灯匠的新作品。

## 关键对白
灯匠：灯要先让人愿意看，再让人知道它想照哪里。
姜阿棠：这句话你可以多收两文钱。

## 结局与后续
灯匠把最后一盏无图样的灯送给队伍。玩家可以自己命名。

## 奖励
护符“百花余光”；角色营地装饰。
