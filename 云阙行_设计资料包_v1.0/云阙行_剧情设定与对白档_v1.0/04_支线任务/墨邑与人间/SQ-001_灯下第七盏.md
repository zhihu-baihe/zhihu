# SQ-001 灯下第七盏

**任务编号：** SQ-001  
**区域：** 砺剑镇／墨邑古城  
**类型：** 小人物／跨章节  
**触发条件：** 砺剑镇河边老妇人每晚点六盏灯，坚持说有七个孩子。

## 流程
第一次只听她说；在墨邑灯会遇见卖糖画的老人，得知多年前有孩子在洪水中失踪；中期在酆都查到一份缺页的孩童记录；返回老妇人处，选择是否告诉她完整真相。

## 关键对白
老妇人：我不是记错。我每天都数。
沈照野：那第七盏要点在哪里？
老妇人想了很久：门口吧。孩子回来，总要认得家。

## 结局与后续
她得知孩子的名字，却没有得到复活的奇迹。之后她依旧点七盏灯，但不再说孩子还会回来。

## 奖励
旧灯芯；终局可用于唤醒一名无名客。
