# SQ-002 铁匠的旧账

**任务编号：** SQ-002  
**区域：** 砺剑镇  
**类型：** 轻松／材料  
**触发条件：** 铁匠抱怨有人欠他一枚铜钉，账本却找不到名字。

## 流程
询问镇上三名 NPC，找到一张旧收条；铜钉被当作玩具塞进小孩的风车；归还后得知铜钉来自一条已经不存在的街。

## 关键对白
铁匠：我不在乎钱。我就是不喜欢账上缺一笔。
姜阿棠：这话听着耳熟。
裴渡：账目完整是基本要求。
沈照野：好了，三个人里有两个不适合做朋友。

## 结局与后续
铁匠把铜钉装进护手，作为第一件锻造材料。

## 奖励
基础锻材、铁匠铺折扣。
