## 新增关键约定
1. 主属性与战术属性分层显示，避免人物面板成为数值墙。
2. 速度影响行动条；暴击、命中、效果命中、破势、定神各有独立用途。
3. “运”只影响非关键额外材料，不影响主线和专属奖励。
4. 五灵亲和作为元素构筑维度，对应元素伤害与状态积累各自上限 +10%。
5. 所有数值是首版待测值，必须经过垂直切片与自动化测试。
