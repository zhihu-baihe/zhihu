# 云阙行：九灯照夜 — 武器系统资料包

版本：v1.0

## 文件说明
- `云阙行_九灯照夜_武器锻造注灵系统设计案_v1.0.docx`：完整可编辑设计文档。
- `云阙行_九灯照夜_武器锻造注灵系统设计案_v1.0.pdf`：便于阅读/评审的 PDF 版。
- `云阙行_武器装备数据样表_v1.0.json`：武器、剧情故物、配方、BOSS 奖励、注灵、铭刻、材料的数据化样表。
- `云阙行_武器装备数据表_v1.0.xlsx`：便于策划和 Excel 编辑的多工作表目录。
- `weapon_catalog.csv` 等 CSV：可用于导入、脚本校验或转换为 UE DataTable。
- `weapon_silhouette_design.png`：原创结构剪影示意。
- `weapon_crafting_flow.png`：锻造流程示意。

## 核心规则
1. 故事兵器与战斗装备分离：剧情物件不占战斗主武器槽；实战使用购买、熔铸、任务或 BOSS 奖励的武器。
2. 熔铸、锻冶、注灵、铭刻各司其职。锻冶无失败惩罚，注灵可拆换，词条有上限且不采用无限随机洗练。
3. 全部武器展示名和 WeaponID 已自动查重。
4. 数值均为首版建议，后续要基于可玩原型进行平衡，不视为最终定稿。
