# 《云阙行：九灯照夜》人物属性与面板沟通速记 v1.1

## 本次新增
- 人物属性系统：气血、灵息、物攻、术攻、防御、灵抗、速度、暴击率、暴击伤害、命中、闪避、破势、定神、效果命中、运、五灵亲和。
- 四名主角均有 Lv.1/20/40/60/80 无装备成长目标；数值是垂直切片初值，不是最终平衡。
- 速度影响行动条；暴击率正常敌人有效上限 65%；暴伤建议上限 250%；闪避上限 35%；定神控制抵抗建议上限 65%。
- 运只增加额外普通材料收益：min(8%, 运×0.08%)；不影响主线、专属武器、配方、BOSS 首通奖励与结局。
- 五灵亲和 0—100；每 10 点提供 1% 对应元素伤害与 1% 状态积累效率，各自上限 +10%。
- 新增 1—80 级修习系统：Lv.5 至 Lv.75 每 5 级获得 1 点，共 15 点；Lv.80 获得终局专精。
- 新增人物面板 UI 规格与程序绘制的布局原型图；深夜蓝、纸白、铜金、玉绿，避免过度发光与数值墙。

- `ATTR-02` 四人 1—80 级成长曲线
- `ATTR-03` 暴击/速度/命中/闪避/破势/定神公式
- `ATTR-04` 运与五灵亲和
- `UI-CHAR-01` 人物面板 UI
