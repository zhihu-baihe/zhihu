云阙行 · 墨邑花灯节 Demo

运行方法：
1. 解压 ZIP。
2. 双击 index.html，推荐使用最新版 Chrome 或 Edge。
3. 点击“进入花灯节”。

本 Demo 是浏览器交互原型：探索/任务簿/队伍切换、NPC 对话、线索推进、行动条视觉、可操作战斗指令、多阶段 BOSS、奖励与浏览器本地保存均可体验。

说明：游戏场景背景为概念预演图片，不是 UE5 实时 3D 场景。该 Demo 用于验证交互流程与战斗规则，后续可把成熟的玩法规则迁移到 Unreal Engine 工程中。

快捷键：战斗中 1 普攻、2 技能、3 仙术、4 道具、5 防御、Q 观察灯阵。
