# CHAR-UI-02 清爽单机仙侠 UI v0.4

## 内容
- `CHAR-UI-02_清爽单机仙侠UI视觉规范_v0.4.docx`：视觉规范、7 个页面原型、UMG 组件拆分、验收标准与参考来源。
- `CHAR-UI-02_清爽单机仙侠UI视觉规范_v0.4.md`：同内容 Markdown 源文档。
- `screens/*.png`：1920×1080 高保真静态界面原型。
- `screens/*.svg`：对应的可编辑矢量原型，文字和布局可以继续改。
- `清爽单机版_UI原型总览.jpg`：7 张原型缩略总览。
- `UI_StyleTokens.csv`：统一色彩 Token。
- `UI_WidgetSpec.csv`：UE5 UMG 页面/组件交付建议。

## 设计方向
温润纸白、青灰墨色、克制朱砂；用留白和细线分组；页面按状态、装备、技能、物品、战斗、对话分开；不做网游化战力总分、发光稀有度边框和过度卡片化。参考《仙剑奇侠传四》的经典单机 RPG 信息分层与清晰菜单分工，但不复制原版素材或精确界面。

## 开发注意
截图中的人物/场景画面是比例与美术气质占位图，不是实机资产。正式 UE5 项目应替换为实时角色渲染/最终美术资源。属性单位与战斗公式仍以项目总档最后确认版本为准。
